# 设计说明

## 1 设计目标

围绕工程师的任务组织设备、告警、诊断与权限页面，使招聘方可以体验一条完整业务路径。使用浅色背景、紧凑表格和明确操作层级；以文字标签同时传达状态，不依赖颜色单独区分。

## 2 页面与业务

### 2.1 设备中心

提供编号搜索、市场和状态筛选；保留数据更新时间与远程能力范围。详情弹窗处理快速查看，排查入口承接完整任务。无匹配结果时提供空态与重置。

### 2.2 告警中心

告警确认与故障解决分开。确认只表示已查看，不自动清除故障。点击排查携带设备上下文，减少重复查找。

### 2.3 远程诊断

左侧承载运行信息和排查建议，右侧展示告警线索与操作权限。离线设备明确展示数据缺失，避免把过期数据当实时数据。诊断建议使用预设条目，并明示知识来源和演示性质。

### 2.4 权限管理

展示角色能力示意及临时授权申请。无操作权限时进入申请流程，说明对象、范围、时长与原因；提交后保留待审批状态。此流程为公开演示设计，不等同于实际企业权限规则。

## 3 已实现交互

设备搜索和筛选、详情弹窗、带设备上下文跳转、告警确认、演示诊断建议、反馈选择、临时权限申请、表单校验、申请列表和空状态。全部使用本地模拟数据。

## 4 与实习项目的关系

案例文档记录实际项目背景、工作和结果。网页集以设备查询、远程诊断、权限管理、AI辅助排查等真实业务主题为基础进行独立重绘；为连贯演示补充的字段、权限申请交互和反馈状态属于作品设计，不作为原项目上线事实。
